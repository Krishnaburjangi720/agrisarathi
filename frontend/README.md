# AgriSārathi Frontend

> **Status:** Planned for Phase 6.
> This directory will contain the React + TypeScript frontend application.

## Planned Setup

```bash
npx -y create-vite@latest ./ -- --template react-ts
npm install
npm install tailwindcss @tailwindcss/vite recharts
npm run dev
```

## Planned Features

- Farm and field data entry forms
- Soil test input with validation
- Dashboard with crop suitability results
- Weather conditions display
- Recommendation review and approval workflow
- Recharts data visualization
- PDF report download
